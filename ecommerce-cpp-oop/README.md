# E-Commerce Shopping Management System (C++ OOP)

A simple shopping app that demonstrates OOP: classes, objects, constructors,
encapsulation, inheritance and polymorphism.

- `cpp/main.cpp` - the C++ console project (Product, Electronics, Clothing, Customer, Cart).
  Run: `g++ main.cpp -o app && ./app`
- `index.html`, `style.css`, `script.js` - web front end with the same class design.
- `images/` - product photos (smartphone, headphones, tshirt, jeans, keyboard).

Flow: Home -> Products -> Add to cart -> Cart -> Customer details -> Bill
